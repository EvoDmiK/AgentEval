# 공개 데이터 마스킹 기록

2026-10-12에 데이터셋, 검토 문서, 템플릿, 이전 문항과 인수인계 기록을 공개용으로 정제했다.

- 실제 서비스 도메인은 `example.invalid` 하위 주소로, 사용자·저장장치·SSH 경로는 가상 경로로 치환했다. 사설 IP는 문서 예시 주소 `192.0.2.10`으로 바꿨다.
- 프로젝트·보관함·운영 서비스 이름과 Grafana의 dashboard/datasource/folder UID는 일관된 예시 식별자로 치환했다. 관련 파일명과 문항 내 참조도 함께 변경했다.
- G09/G10의 합성 API 키·비밀번호는 서로 다른 `MASKED_DUMMY_*` 값으로 바꾸고 시드, 근거, 정답, 비저장 감사 마커에 동일하게 적용했다. 이 값들은 실제 자격 증명이 아니다.
- 인수인계의 실제 run ID 및 운영 보안·접근권한·장애 대응 상세는 마스킹했다.
- 통합 `questions.csv`, `records.json`, `manifest.json`은 정제한 원본 문항에서 다시 생성했다. manifest의 파일 해시는 공개본을 검증한다.
- F의 원본 도구 응답 해시·바이트 수는 공개본에서 제외했다. `public_excerpt_sha256`은 UTF-8로 인코딩한 공개 `excerpt` 문자열의 SHA-256이다. 발췌가 잘린 경우 전체 응답의 무결성을 입증하지 않는다.
- `materials/snapshot-manifest.csv`의 공개 파일 해시·줄 수는 다시 계산했다. 비공개 출처의 원본 해시는 비워 두었다. 목록의 비공개 출처 원문은 저장소에 포함되지 않는다.

E 문서의 오류 주입 내용과 채점 기준은 유지했다. 공개본의 운영 식별자·주소는 가상 예시이며 실제 환경 설정으로 사용하지 않는다. 공개 URL과 법령·논문 근거의 사실성은 이번 마스킹 작업에서 새로 검증하지 않았다.

마스킹 전 원본은 Git에서 제외되는 `.private-backup/before-publication-20261012/`에 해시를 대조해 보존했다. 원본 실행 로그, 런타임·자격 증명, 배포 전용 스크립트와 지식 그래프는 공개하지 않았다. 이 작업은 과거 Git 이력 재작성이나 외부 복사본 회수를 수행하지 않는다.
