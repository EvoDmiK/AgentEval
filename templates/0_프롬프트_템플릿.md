# 프롬프트 템플릿 (두 에이전트에 똑같이 사용)

## A·B·C·D 유형 (obsidian_vault MCP 사용)
```
obsidian_vault 도구로 ExampleVault 보관함에서 찾아 답하라.
- 읽어도 되는 폴더: Work/, Dev/, Learning/. Private/ 와 resume/ 는 읽지 마라.
- 답과 함께 근거 문서 경로와 해당 문장을 그대로 인용하라.
- 문서에서 확인할 수 없으면 추측하지 말고 "문서에서 확인할 수 없음"이라고 답하라.
- 질문에 틀린 전제가 있으면 먼저 바로잡아라.

질문: {질문}
```

## E 유형 (오류 찾기, 문서 본문을 프롬프트에 포함, 도구 사용 금지)
```
아래 문서에는 사실 또는 논리 오류가 여러 개 들어 있다. 도구를 쓰지 말고 문서 안의 내용만으로 오류를 모두 찾아라.
각 오류마다 (1) 위치(줄 또는 문장), (2) 틀린 내용, (3) 올바른 내용 또는 모순되는 근거를 적어라.
오류가 아닌 것을 오류로 지적하지 마라. 확실하지 않으면 "불확실"로 표시하라.

--- 문서 시작 ---
{materials/E?_*.md 본문}
--- 문서 끝 ---
```

## 공통 규칙
- 문항마다 새 세션으로 시작한다.
- 보관함 폴더 `Private/`는 읽지 못하게 프롬프트로만 막고 있다. 실제 차단이 아니다.
